SYSTEM 04

시트 자동화 (Apps Script)

스프레드시트가 직접 일을 합니다. 체크박스 하나에 슬랙 알림과 데이터 동기화가 자동으로 일어납니다.

💼
매출현황
6개 팀별 탭에 진행건을 입력 → C열 체크 시 세금발행 큐로 이동, Slack 채널에 자동 알림.
🧾
세금발행
5분마다 매출현황을 폴링해 발행 대기 항목을 월별 시트로 자동 동기화.
💸
입금요청
팀별 탭에서 입금요청 → 다이얼로그 → 경영지원 웹앱 전송 → Slack 알림 + 이체현황 자동 등록.
🏦
이체현황
이체완료 체크 → 팀 시트 동기화 + 요청자에게 슬랙 DM. 월별 마감/사업소득 정리 자동화.

💡 사용자 입장에선 그냥 시트에 체크박스 클릭만 하면 끝. 뒤에서는 Apps Script가 알림을 쏘고, 다른 시트로 데이터를 옮기고, 슬랙 메시지를 갱신합니다.

시트 자동화 · 실전 흐름

체크박스 한 번이면 끝

시트에서 일어나는 일과 슬랙으로 오는 알림이 자동으로 이어집니다.

💼 매출 → 세금발행 흐름

STEP 1. 팀장이 매출현황 시트의 자기 팀 탭에 프로젝트 정보 입력 (브랜드·진행내용·금액·이메일 등)
STEP 2. C열 체크박스 클릭 (세금발행 요청)
⚡ 자동 발생
  • 세금계산서 채널에 멘션 + 발행정보 메시지
  • 5분 안에 세금발행 시트 월별 탭으로 자동 이동
  • 취소 시 같은 스레드에 답글로 알림

💸 입금요청 → 이체 흐름

STEP 1. 팀원이 입금요청 시트 메뉴 → 📋 입금요청 처리 다이얼로그
STEP 2. 결제유형(기안서/사업소득/제품구매) + 금액·계좌·증빙 입력
⚡ 자동 발생
  • 경영지원팀 채널에 입금요청 알림
  • 이체현황 시트에 자동 등록
  • 경영지원이 이체완료 체크 시 → 요청자에게 슬랙 DM
💡 결과적으로  —  팀장은 매출 입력만, 팀원은 다이얼로그 채우기만, 경영지원은 체크만.
나머지(알림·동기화·기록)는 모두 Apps Script가 자동으로 처리합니다.
